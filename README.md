# ATM Interface

## Description
A console-based ATM simulation developed in Java that allows users to check balance, deposit money, and withdraw money.

## Features
- Check account balance
- Deposit money
- Withdraw money
- Insufficient balance handling
- Menu-driven interface

## Technologies Used
- Java
- OOP Concepts (Classes and Objects)
- Scanner Class

## How to Run
1. Compile the program:
   javac ATMInterface.java

2. Run the program:
   java ATMInterface
